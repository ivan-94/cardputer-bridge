Cardputer Bridge

三步接入你的 Cardputer

把 App 拖入“应用程序”，明确允许首次打开，再由 App 完成系统麦克风与固件设置。

1

安装应用

回到此磁盘窗口，将 Cardputer Bridge 拖到右侧的 Applications。复制完成后，从“应用程序”文件夹打开。

!

如果看到“Apple 无法验证”

  1. 看到“未打开 Cardputer Bridge”和“移动到废纸篓”时，点击完成，不要移到废纸篓。
  2. 打开系统设置 → 隐私与安全性，滚动到“安全性”。
  3. 在 Cardputer Bridge 提示旁点击仍要打开，认证后再次选择“打开”。

当前版本使用 ad-hoc 签名，更新后 macOS 可能再次要求确认。请只从项目 GitHub Release 下载，并校验 SHA-256。

2

安装系统麦克风

在首次设置的“系统麦克风”步骤点击安装系统麦克风。macOS 会显示一次标准管理员授权框；成功后可在录音、会议和语音 App 中选择 Cardputer Microphone。

3

连接 Cardputer

通过 USB 连接 Cardputer-ADV，按引导安装固件，然后完成蓝牙配对与 2.4 GHz Wi-Fi 配置。后续固件可直接通过 App 更新。

Apple silicon · macOS 15+
